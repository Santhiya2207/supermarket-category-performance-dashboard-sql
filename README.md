# Supermarket Category Performance Dashboard Using SQL

## Project Overview

This project analyzes supermarket sales data using SQL to understand category performance, product revenue, and business trends.

## Objectives

* Analyze total revenue by product and category.
* Rank products and categories based on revenue.
* Calculate revenue contribution and profit margin.
* Identify business insights from sales data.

## Tools Used

* MySQL
* SQL

## SQL Concepts

* SELECT, WHERE, DISTINCT
* Aggregate functions: SUM, AVG, COUNT
* GROUP BY and HAVING
* JOINs and subqueries
* CASE statements
* Window functions: RANK()
* Revenue and profit analysis

## Project Files

* `supermarket_category_performance.sql` — SQL queries for analysis.
* `Supermarket_Category_Performance_Dashboard_Using_SQL_-_Project_Report.docx` — Project documentation.

## Key Learning

Practiced SQL-based data analysis, ranking, aggregation, and extracting insights to support business decisions.
